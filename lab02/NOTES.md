Рабочая папка - это текущая папка проекта, где  мы создаём и редактируем файлы на данный момент.
Индекс - это подготовленное состояние файлов перед сохранением.
Коммит - это сохранённая определённая версия проекта в локальной базе данных Git.
Git и GitHub различаются следующим: Гит - локальная система для контроля версий, в то время как ГитХаб - облачный сервис, где можно размещать репозитории и иметь возможность давать доступ к ним другим людям (участникам команды и т.п.).
