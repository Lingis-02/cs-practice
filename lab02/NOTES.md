Рабочая папка - это текущая папка проекта, где  мы создаём и редактируем файлы на данный момент.
Индекс - это подготовленное состояние файлов перед сохранением.
Коммит - это сохранённая определённая версия проекта в локальной базе данных Git.
Git и GitHub различаются следующим: Гит - локальная система для контроля версий, в то время как ГитХаб - облачный сервис, где можно размещать репозитории и иметь возможность давать доступ к ним другим людям (участникам команды и т.п.).
Использованные команды:
git status - показывает состояние рабочей директории и индекса на данный момент (какие файлы изменены).
git diff - показывает изменения в рабочей папке, которые еще не внесены в индекс.
git diff --staged - показывает изменения, которые уже подготовлены в индексе и войдут в следующий коммит.
Ветки:
Ветка - это ссылка на коммит. При новом коммите ветка продвигается вперед, указывая на самый "свежий" коммит. Слияние - это объединение изменений из одной ветки в другую.
