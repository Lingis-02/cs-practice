git log показывает историю коммитов (кто, когда и с каким комментарием сделал изменения).
git show показывает изменения кода внутри одного конкретного коммита.
git diff отображает разницу в коде между двумя состояниями проекта, коммитами или ветками.
git log -S"def" нашла все коммиты, в которых добавлялись или удалялись строки, содержащие "def".
git blame построчно проанализировала файл и показала, какой автор, в каком коммите и в какую дату написал каждую конкретную строчку кода.


git restore calc.py отменяет незакоммиченные изменения в текущей рабочей папке.
git restore --source=HEAD~2 calc.py временно восстанавливает состояние файла из коммита двух шагов назад (HEAD~2).
